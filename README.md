# Запуск алгоритма

```bash
python3 plan_batch.py
```

```bash
python3 plan_batch.py red 200 yellow 157 green 245 black 71 --output reports/batch
```

```bash
python3 plan_batch.py --input input.json --output reports/batch
```

## Доступные аргументы

| Аргумент | Описание |
| --- | --- |
| `TYPE COUNT [TYPE COUNT ...]` | Пары типа и количества коробок из `config/box_catalog.json` (например, `red 200 yellow 157`). |
| `example` | Сгенерировать случайную партию с 20 SKU; без аргументов запускается этот режим с открытием HTML. |
| `--input PATH` | Входной JSON с размерами в миллиметрах; нельзя совмещать с парами `TYPE COUNT`. |
| `--output PATH` | Каталог результатов (по умолчанию `reports/example` для `example`, иначе `reports/batch`). |
| `--demo-count N` | Количество коробок в генерируемой партии (по умолчанию `500`, для `example` не менее `20`). |
| `--seed N` | Seed для генерации случайной партии (в `example` по умолчанию не задан). |
| `--min-support X` | Минимальная доля площади опоры коробки (по умолчанию `0.85`). |
| `--min-layer-fill X` | Целевая доля заполнения площади слоя (по умолчанию `0.75`). |
| `--time-limit N` | Мягкий лимит поиска в секундах (по умолчанию `0`, без ограничения). |
| `--max-additions N` | Максимальное число дополнительных коробок (по умолчанию без ограничения; `0` запрещает добавления). |
| `--max-addition-area X` | Устаревший параметр; в режиме полной доставки ограничение на площадь добавлений не используется. |
| `--max-leftovers N` | Устаревший параметр; в режиме полной доставки исходные коробки не откладываются (по умолчанию `0`). |
| `--list-types` | Показать доступные типы коробок и размеры. |
| `--open` | Открыть итоговый HTML-отчёт в браузере. |
| `-h`, `--help` | Показать справку по аргументам. |
